# Malavika Manila Raveendran - Professional Developer Portfolio

A modern, responsive, and professional developer portfolio website built for **Malavika Manila Raveendran** (Python Full-Stack Developer & MCA Scholar), based on her professional resume.

---

## 🌟 Highlights & Features

- **Semantic HTML5 & Modern CSS3**: Fast, lightweight, zero build-step required.
- **Dual Dynamic Themes**:
  - **Dark Mode (Default)**: Sleek **Black + Grey** palette (obsidian black backgrounds, charcoal glassmorphic cards, platinum silver metallic accents and typography).
  - **Bright / Light Mode**: Striking **White + Red** palette (pure crisp white backgrounds, subtle clean borders, vibrant crimson red accents, red buttons, and glowing highlights).
  - Persistent user preference saved in `localStorage` with system preference auto-detection.
- **Dynamic Hero Section**:
  - Live typing effect showcasing core specializations.
  - Interactive Python developer code card with syntax styling.
  - Quick contact badges, direct mail & phone links, and social links (LinkedIn, GitHub).
- **Comprehensive Resume Representation**:
  - **About / Professional Summary**: Complete profile statement with career objective.
  - **Technical Skills**: Structured categories for Programming Languages, Frameworks & Libraries, Web Technologies, Databases, Dev Tools, and Generative AI/Creative tooling.
  - **Featured Projects**: Detailed architectural breakdowns and accomplishment bullet points for *La Fashionista*, *Mock Interview (AI Assessment System)*, and *Pet Paradise*.
  - **Experience Timeline**: Career history at *Luminar Technolab* and *GEMS Groups* with responsibilities and tech stack badges.
  - **Education**: MCA (AWH Engineering College) & BCA (Sree Narayana College).
  - **Languages**: Proficiency meters for English, Malayalam, Tamil, and Hindi.
  - **Direct Contact**: Interactive contact form with auto-mail composer, direct phone dialer, and one-click copy email button with toast notification.
- **Fully Responsive**: Smoothly adapts to mobile screens, tablets, laptops, and widescreen monitors.

## 🚀 How to Run Locally

You don't need any complex installation. Simply open `index.html` in your web browser:

1. Double-click `index.html` in your file explorer, **OR**
2. Use VS Code's **Live Server** extension: right-click `index.html` and click **"Open with Live Server"**.

## 🌐 Free 1-Click Deployment Options

### 1. GitHub Pages (Recommended)
1. Initialize git and push to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/MalavikaRaveendran/<repository-name>.git
   git push -u origin main
   ```
2. In your repository on GitHub, go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and save. Your portfolio will be live at `https://malavikaraveendran.github.io/<repository-name>/`.

### 2. Vercel / Netlify
- Drag and drop this folder directly into the [Netlify Drop](https://app.netlify.com/drop) or import from GitHub into [Vercel](https://vercel.com).
